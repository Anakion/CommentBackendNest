# Система комментариев

Мощная система комментариев с вложенными ответами, вложениями файлов и защитой CAPTCHA. Построена на FastAPI, SQLAlchemy и WebSockets.

## 🌟 Возможности

- **Вложенные комментарии**: Поддержка многоуровневых вложенных комментариев
- **Обновления в реальном времени**: Интеграция с WebSocket для мгновенных обновлений
- **Вложения файлов**: Поддержка изображений и текстовых файлов
- **Защита CAPTCHA**: Предотвращение спама и автоматических отправок
- **Пагинация и сортировка**: Эффективная загрузка комментариев с различными вариантами сортировки
- **RESTful API**: Чистые и хорошо документированные эндпоинты
- **Поддержка Docker**: Простое развертывание с использованием Docker и Docker Compose

## 🚀 API Эндпоинты

### Комментарии

- `POST /api/v1/comments/` - Создать новый комментарий
  ```
  Content-Type: multipart/form-data
  
  text: string (обязательно)
  username: string (обязательно)
  email: string (обязательно, валидный email)
  homepage: string (опционально, URL)
  parent_id: integer (опционально, ID родительского комментария)
  captcha_id: integer (обязательно, ID капчи)
  captcha_text: string (обязательно, текст капчи)
  image_file: file (опционально, изображение)
  text_file: file (опционально, текстовый файл)
  ```

- `GET /api/v1/comments/` - Получить список комментариев с пагинацией
  ```
  Параметры запроса:
  - page: номер страницы (по умолчанию: 1)
  - per_page: количество на странице (по умолчанию: 25, максимум: 100)
  - sort_by: поле для сортировки (username|email|created_at, по умолчанию: created_at)
  - order: порядок сортировки (asc|desc, по умолчанию: desc)
  ```

- `GET /api/v1/comments/{comment_id}` - Получить конкретный комментарий с ответами
- `GET /api/v1/comments/{comment_id}/replies` - Получить ответы на комментарий

### CAPTCHA

- `GET /api/v1/captcha/` - Получить новую CAPTCHA
- `POST /api/v1/captcha/validate` - Проверить ответ CAPTCHA

### WebSocket

- `ws://<хост>/ws` - WebSocket эндпоинт для обновлений в реальном времени

## 🛠️ Технические детали реализации

### Стратегия загрузки комментариев

Система использует стратегию `selectinload` от SQLAlchemy для эффективной загрузки вложенных комментариев с ограничением в 5 уровней вложенности для предотвращения проблем с производительностью. Рекурсивная загрузка реализована в классе `CommentRepository` с помощью вспомогательной функции:

```python
def load_replies(level=0):
    if level > 5:  # Защита от бесконечной рекурсии
        return selectinload(Comment.replies)
    return selectinload(Comment.replies).options(
        selectinload(Comment.user),
        load_replies(level + 1)
    )
```

### Работа с файлами

- **Изображения**: Автоматическое изменение размера и конвертация в формат webp
- **Текстовые файлы**: Сохранение с проверкой размера
- Файлы сохраняются в директории `/uploads`

## 🚀 Начало работы

### Предварительные требования

- Docker и Docker Compose
- Python 3.9+

### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <адрес-репозитория>
   cd CommentBackendNest
   ```

2. Создайте файл `.env` на основе `.dev.env`:
   ```bash
   cp .dev.env .env
   ```

3. Соберите и запустите контейнеры:
   ```bash
   docker-compose up --build -d
   ```

4. Примените миграции базы данных:
   ```bash
   # Войдите в контейнер web
   docker-compose exec web bash
   
   # Примените миграции
   alembic upgrade head
   ```

5. API будет доступно по адресу `http://localhost:8000`

### Переменные окружения

- `DATABASE_URL`: Строка подключения к PostgreSQL
- `SECRET_KEY`: Секретный ключ для JWT токенов
- `UPLOAD_DIR`: Директория для загружаемых файлов
- `MAX_FILE_SIZE`: Максимальный размер файла в байтах
- `ALLOWED_EXTENSIONS`: Список разрешенных расширений файлов через запятую

## 🧰 Разработка

### Запуск вручную

1. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Для Windows
   ```

2. Установите зависимости:
   ```bash
   pip install -e ".[dev]"
   ```

3. Запустите сервер для разработки:
   ```bash
   uvicorn src.main:app --reload
   ```
